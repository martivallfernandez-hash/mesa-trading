# Mesa de Trading

Mesa de trading personal para practicar en cuenta demo:

- **Mercado**: precios de divisas, oro y cripto en tiempo real (TradingView y Binance), cruces de divisas y calendario económico.
- **Gráfico**: gráfico avanzado de TradingView y resumen técnico por activo.
- **Riesgo**: calculadora de lotes según balance, % de riesgo, entrada, stop y objetivo.
- **Diario**: registro de operaciones con estadísticas (acierto, factor de beneficio, esperanza, R, máxima caída) y curva de capital.

Los datos del diario se guardan solo en el navegador. Herramienta de aprendizaje: no es asesoramiento financiero.
